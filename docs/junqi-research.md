# Junqi / 军旗 research notes

BoardSight treats Junqi as an imperfect-information extension of the existing "control map" idea. The product goal is not merely to recommend a move, but to expose direct control, probabilistic danger, hidden-piece beliefs, information value and the reasoning behind candidate actions.

- Useful concepts: board terrain, camps, headquarters, railway movement, engineer turns, hidden setup and lightweight AI.

- License: MIT.

## BoardSight architecture

The Junqi path should remain separate from the deterministic chess/Xiangqi control-map adapter:

1. **Rule engine**
   - board topology, road/rail graph, camps and headquarters
   - setup legality
   - movement legality
   - combat resolution

2. **Belief engine**
   - per-hidden-piece probability distribution
   - hard exclusions from rules
   - posterior updates from movement history and combat observations
   - remaining-inventory coupling

3. **Sight / risk engine**
   - deterministic friendly control
   - probabilistic enemy threat
   - strategic nodes and mobility
   - information gain from probing actions

4. **Decision engine**
   - generate legal candidate actions locally
   - deterministic/rule-based baseline scorer
   - optional search or DeepNash/RNaD-style policy later
   - optional Jev scorer: state + candidate actions -> action probabilities

5. **Explanation layer**
   - summarize threats, beliefs and candidate-action tradeoffs
   - keep natural-language explanation downstream from rules/decision logic

## Why Jev belongs here more than in standard chess

Standard international chess is a perfect-information game; the full position is visible, so Stockfish-class search remains the natural tactical/strategic engine.

Junqi is imperfect-information. A decision model that scores a finite set of legal actions probabilistically is a better fit, provided:
- legal moves are generated by deterministic code;
- hidden-piece beliefs are produced by a dedicated belief engine;
- Jev ranks candidates rather than inventing rules or board state.

Target pipeline:

`history -> belief posterior -> risk map -> legal actions -> features -> Jev/search scorer -> explanation`

## Implemented on feat/junqi-sight

- 12×5 board surface
- standard road/rail graph, camps, headquarters and three center crossings
- legal movement including engineer railway turns
- protected occupied camps and headquarters immobility
- mine/flag immobility and full rank/bomb/mine combat resolution
- flag capture and flag exposure after marshal loss
- deterministic hidden setup with concealed true identities for local play
- actual red-player move execution and local blue AI replies
- initial-square-aware setup priors for flag, mines and bombs
- history observations for movement, engineer-only turns and combat outcomes
- globally coupled hidden-piece posterior distributions
- per-piece probabilistic influence overlay without true-identity leakage
- whole-board probabilistic risk heatmap
- candidate-action scoring using capture expectation, risk, mobility, advance and information value
- move history and rule-based natural-language explanation
- Jev integration point documented but intentionally not a hard dependency
